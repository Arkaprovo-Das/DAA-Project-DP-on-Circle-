# DAA-Project-DP-on-Circle-
By Arkaprovo Das (Bmat2408) and Priankar Biswas (Bmat2421)

The points in P are taken as angles in the range [0, 2π). And the
intervals are taken as a tuple, [a, b], where the interval I_j over the circle is
{exp(iθ) : θ varies in [a, b] in counterclockwise orientation} and a, b are in the
range [0, 2π).
